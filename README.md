# Elsewhere ✿

> a living corner of the internet made from golden-hour glass, rain, strange little rooms, and an unreasonable number of cats.

**Elsewhere** is the world behind [xaynakive.com](https://xaynakive.com).

It is my personal portfolio, but it was never meant to feel like a résumé. It shifts between day and night, rains when it feels like it, and keeps pieces of my work, history, and imagination hidden behind objects waiting to be touched.

**[enter Elsewhere →](https://xaynakive.com)**

## places within

- **Mythirium** — a rotating multidimensional artifact with four faces and four fragments of its creator
- **selected worlds** — projects where software, design, and strange ideas meet
- **the archive** — everything shipped, abandoned, unfinished, remembered, or built at 3 AM
- **Glasstapes** — a glass guestbook where visitors leave words, drawings, and traces of themselves
- **Ocean** — my personal assistant, living quietly inside Elsewhere
- **how I got here** — the story from broken gadgets and old web pages to intelligent systems and interfaces

## the atmosphere

- golden-hour glass and soft blur
- daylight, darkness, rain, and small rainbows
- hidden drawers, unfolding cards, and tactile interactions
- interfaces inspired by old websites and future operating systems
- cats, naturally

## built with

- HTML
- CSS
- vanilla JavaScript
- CSS 3D transforms
- Canvas
- Supabase
- an unreasonable amount of atmosphere

No framework. No build step. Just files you can open and a world built by hand.

## run locally

Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/xaynakive/elsewhere.git
cd elsewhere
```

Some connected features, including Glasstapes, may require their corresponding Supabase configuration.

## constellation

- **[Mythirium](https://github.com/xaynakive/mythirium)** — the interactive 3D artifact at the entrance
- **Glasstapes** — the visitor-made memory room
- **Ocean** — the intelligence beneath the surface

Elsewhere is the place. Everything else is something you discover inside it.
